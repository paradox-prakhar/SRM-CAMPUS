# Presentation demo

No accounts, Google Maps key or Firebase project are required.

1. Launch the app and choose **Explore interactive demo**. The screen says SIMULATION.
2. Search Library or filter Study. Select Central Library on the illustration or list.
3. Choose Get directions. The fictional route shows 240 m / 4 min. Press Walk to animate the blue simulated student; Pause and restart are supported.
4. Open the library card again and tap the indoor layers button. Select Ground floor then First floor. The source is labelled manual.
5. Tap Simulate scanning this QR. The library first-floor checkpoint is validated in the demo namespace and the confirmation source changes to QR. Alternatively scan the displayed QR using a second display/device.
6. Search a demo room and tap it to highlight the illustrative corridor.
7. Open Live sharing. Invite the demo friend for a selected duration. The simulated friend appears; Stop Sharing removes the map and clears the simulated session. No real location reaches Firebase.
8. Open Friends to add/remove local demo friends. Settings offers dark appearance and Reset demo.
9. Explore 360° opens the university's official tour page in the external browser.

Say explicitly: “This map and its distances, floors and friend positions are fictional presentation fixtures. Live mode requires surveyed campus data and configured services.” The app does not claim automatic floor detection or real campus route accuracy.
